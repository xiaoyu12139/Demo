# PySide 窗口应用

这是一个使用 PySide6 创建的桌面应用程序，展示了如何创建带有菜单栏、操作区域和画布区域的窗口应用。

## 功能特性

- **菜单栏**: 包含文件、视图和帮助菜单
- **左侧操作区域**: 包含各种控件（文本输入、数值选择、复选框、单选按钮、滑块等）
- **右侧画布区域**: 使用 QStackedWidget 实现多个视图切换
  - 文本编辑器视图
  - 列表视图
  - 绘图区域视图

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行应用

```bash
python main_window.py
```

## 使用说明

1. **菜单栏操作**:
   - 文件菜单: 新建、打开、退出功能
   - 视图菜单: 切换不同的画布视图
   - 帮助菜单: 显示关于信息

2. **操作区域**:
   - 基本控件组: 文本输入框、数值选择器、复选框
   - 选择模式: 三个单选按钮选择不同模式
   - 控制组: 滑块控制进度条数值
   - 操作按钮: 执行不同的操作

3. **画布区域**:
   - 通过视图菜单可以切换三个不同的画布
   - 文本编辑器: 用于文本编辑
   - 列表视图: 显示列表项
   - 绘图区域: 显示简单的图形绘制

## 技术特点

- 使用 PySide6 框架
- 模块化设计，每个功能区域独立封装
- 响应式布局，支持窗口大小调整
- 菜单驱动的界面切换
- 丰富的 UI 控件演示
