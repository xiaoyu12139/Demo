# Electron Demo 01

一个功能丰富的 Electron 桌面应用程序演示项目。

## 🚀 功能特性

### 📝 文本编辑器
- 实时文本编辑
- 自动保存到本地存储
- 保存文件到桌面
- 文件加载功能

### 🎨 主题系统
- 浅色主题
- 深色主题
- 蓝色主题
- 主题持久化保存

### 📊 系统信息
- 应用版本显示
- Node.js 版本
- Electron 版本
- Chrome 版本

### 🔧 功能演示
- 系统通知
- 原生对话框
- 文件选择器
- 菜单栏集成

### ⌨️ 键盘快捷键
- `Ctrl+S` / `Cmd+S`: 保存文件
- `Ctrl+N` / `Cmd+N`: 新建文档
- `Ctrl+O` / `Cmd+O`: 打开文件
- `Ctrl+1`: 切换到浅色主题
- `Ctrl+2`: 切换到深色主题
- `Ctrl+3`: 切换到蓝色主题

## 📦 安装和运行

### 前置要求
- Node.js (版本 16 或更高)
- npm 或 yarn

### 安装依赖
```bash
npm install
```

### 开发模式运行
```bash
npm run dev
```

### 生产模式运行
```bash
npm start
```

### 构建应用
```bash
npm run build
```

## 📁 项目结构

```
electron-demo01/
├── main.js          # 主进程文件
├── index.html       # 应用界面
├── renderer.js      # 渲染进程脚本
├── styles.css       # 样式文件
├── package.json     # 项目配置
└── README.md        # 项目说明
```

## 🛠️ 技术栈

- **Electron**: 跨平台桌面应用框架
- **Node.js**: JavaScript 运行时
- **HTML5**: 用户界面标记
- **CSS3**: 样式和主题
- **JavaScript ES6+**: 应用逻辑

## 📋 主要文件说明

### main.js
主进程文件，负责：
- 创建应用窗口
- 管理应用生命周期
- 处理菜单和对话框
- IPC 通信处理

### renderer.js
渲染进程文件，负责：
- 用户界面交互
- 文件操作
- 主题切换
- 与主进程通信

### styles.css
样式文件，包含：
- 响应式布局
- 多主题支持
- 现代化 UI 设计
- 动画效果

## 🎯 学习要点

这个演示项目展示了以下 Electron 开发概念：

1. **主进程与渲染进程**: 理解 Electron 的双进程架构
2. **IPC 通信**: 进程间通信的实现
3. **原生 API**: 使用系统通知、对话框等原生功能
4. **文件系统**: 读写本地文件
5. **菜单系统**: 创建应用菜单
6. **主题系统**: 动态切换应用主题
7. **本地存储**: 数据持久化
8. **键盘快捷键**: 提升用户体验

## 🔧 自定义和扩展

### 添加新功能
1. 在 `renderer.js` 中添加新的事件处理函数
2. 在 `index.html` 中添加相应的 UI 元素
3. 在 `styles.css` 中添加样式
4. 如需主进程功能，在 `main.js` 中添加 IPC 处理

### 修改主题
1. 在 `styles.css` 中的 `:root` 或主题选择器中修改 CSS 变量
2. 在 `renderer.js` 中的 `setTheme` 函数中添加新主题

### 添加菜单项
1. 在 `main.js` 的 `createMenu` 函数中修改菜单模板
2. 添加相应的点击处理函数

## 🐛 常见问题

### 应用无法启动
- 确保已安装所有依赖：`npm install`
- 检查 Node.js 版本是否符合要求

### 通知不显示
- 确保系统允许应用发送通知
- 在某些系统上可能需要用户授权

### 文件保存失败
- 检查桌面目录的写入权限
- 确保磁盘空间充足
